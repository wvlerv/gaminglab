# GamingLab

A full-stack project for a gaming platform.

## Structure

- `backend/`: Java 21 + Spring Boot + H2 backend
- `frontend/`: Reserved for the frontend application (not initialized yet)

## Backend

```powershell
cd backend
mvn spring-boot:run
```

The backend starts at `http://localhost:8080` and stores data in `backend/data/gaminglab.mv.db`.

See `backend/README.md` for details.
